List Column Logo

Odoo 18.0 – Backend UX Enhancement

Overview

This module adds configurable logos to list view column headers. Administrators can attach a logo to any field via Settings → Technical → Database Structure → Fields and the icon will automatically render in the corresponding list column header across the app.

Key Features

  • Per-field logo stored on a dedicated model with one-to-one linkage
  • Seamless header rendering by inheriting the native list renderer template
  • Optimized image delivery through /web/image URLs with cache busting
  • Responsive sizing aligned with Odoo avatar styles (o_avatar, o_m2o_avatar)
  • “Add a Logo” button on field form to open/create the related logo
  • No changes required to existing list views

How It Works

  1. Go to Settings → Technical → Database Structure → Fields.
  2. Open a field record and click Add a Logo in the header.
  3. Upload an image (the module stores optimized sizes automatically).
  4. Open any list view containing that field; the logo appears in the column header.

Compatibility

Tested on Odoo 18.0 Community/Enterprise with web backend.

Installation

  1. Copy the module directory to your addons path.
  2. Update Apps list and install List Column Logo.
  3. Hard refresh the backend to reload assets.
